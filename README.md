# Skyline Weather

A phone-friendly weather app: current conditions, hourly forecast, live rain radar, rainfall totals and a 7-day forecast for where you are.

Open it at **https://krisscott27-a11y.github.io/weather/** and add it to your home screen:

- **iPhone (Safari):** Share → Add to Home Screen
- **Android (Chrome):** ⋮ → Add to Home screen / Install app

Data: [Open-Meteo](https://open-meteo.com/) (forecast and place search), [RainViewer](https://www.rainviewer.com/) (radar), [BigDataCloud](https://www.bigdatacloud.com/) (place name), map tiles © OpenStreetMap. No API keys needed.
